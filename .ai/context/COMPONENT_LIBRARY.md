# Component Library Catalog

All built components must match this standard catalog to ensure code reuse.

## 🧱 Component Registry

### 1. `Navbar`
- **Purpose**: Global app navigation.
- **Visuals**: Glassmorphic, floating, responsive layout header.
- **States**: Scrolled state (height reduction, border opacity shift).

### 2. `Button`
- **Purpose**: Call to action interactions.
- **Variants**:
  - `Primary`: Neon border/glow accent.
  - `Secondary`: Glassmorphic, thin gray border.
- **Interactive**: Scaling on hover (`scale: 1.05`), magnetic displacement effect.

### 3. `GlassCard`
- **Purpose**: Generic layout container.
- **Visuals**: backdrop blur (`12px`), white semi-transparent border, dark obsidian content area.

### 4. `CTASection`
- **Purpose**: Visual section guiding the user to the contact form.
- **Details**: Glow backgrounds, editorial typography headline, and action button.

### 5. `Footer`
- **Purpose**: Closing container with copyright, sitemap links, and social anchors.
